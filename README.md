# H2/NH3 Combustion Explorer

شبیه‌سازی، بهینه‌سازی و داشبورد تعاملی برای احتراق مخلوط‌های هیدروژن-آمونیا
(کربن‌زدایی از سوخت‌های صنعتی و توربین گاز).

## ساختار پروژه

```
h2nh3_project/
├── src/
│   ├── simulate.py          # هسته‌ی شبیه‌سازی احتراق (Cantera)
│   └── generate_dataset.py  # اسکن پارامتری و تولید دیتاست
├── data/
│   └── combustion_dataset.csv
├── outputs/                 # نمودارها، GIFها، خروجی‌های نهایی
├── notebooks/                # نوت‌بوک‌های اکتشافی
└── requirements.txt
```

## نصب

```bash
pip install -r requirements.txt
```

## مرحله ۱: تولید دیتاست

```bash
python src/generate_dataset.py
```

این اسکریپت روی بازه‌ی کسر مولی H2 (۰ تا ۱۰۰٪) و نسبت هم‌ارزی (۰.۷ تا ۱.۳)
اسکن می‌کند و برای هر نقطه سرعت شعله آرام، دمای آدیاباتیک و غلظت آلاینده‌های
NOx را محاسبه و در `data/combustion_dataset.csv` ذخیره می‌کند.

> نکته: هر شبیه‌سازی ۵ تا ۱۵ ثانیه طول می‌کشد. برای گرید پیش‌فرض (۹۹ نقطه)
> کل فرآیند حدود ۱۵-۳۰ دقیقه زمان می‌برد. برای تست سریع، `n_h2` و `n_phi`
> را در `generate_dataset.py` کاهش دهید.
