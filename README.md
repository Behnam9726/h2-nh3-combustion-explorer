# 🔥 H2/NH3 Combustion Explorer

یک پلتفرم محاسباتی برای شبیه‌سازی، یادگیری ماشین، و بهینه‌سازی احتراق
مخلوط‌های هیدروژن-آمونیا — دو سوخت بدون کربنِ کلیدی برای کربن‌زدایی
تولید برق و توربین‌های گاز صنعتی.

🔗 **دموی زنده:** https://h2-nh3-combustion-explorer-kyvb58epev5e6s8khcmaje.streamlit.app/

> نکته: روی نسخه‌ی رایگان Streamlit Cloud دیپلوی شده؛ اولین بازدید ممکن است
> ۳۰-۶۰ ثانیه طول بکشد تا اپ «بیدار» شود. برخی تب‌ها (تصویر شعله، شعله‌ی
> نفوذی) شبیه‌سازی فیزیکی زنده انجام می‌دهند و چند ثانیه طول می‌کشند —
> این تأخیر عمدی نیست، واقعاً معادلات دیفرانسیل احتراق را حل می‌کند.

---

## چرا این پروژه؟

هیدروژن و آمونیا در احتراق مستقیم CO2 تولید نمی‌کنند، اما این‌که آیا
واقعاً به کربن‌زدایی کمک می‌کنند به دو چیز بستگی دارد: **چطور تولید
می‌شوند** (سبز/آبی/خاکستری) و **چقدر خوب آلاینده‌ی NOx ناشی از احتراقشان
مدیریت می‌شود**. این پروژه دقیقاً روی بخش دوم (شیمی احتراق، NOx، و
پایداری شعله) با ابزارهای شبیه‌سازی، یادگیری ماشین و بهینه‌سازی عددی
تمرکز کرده است.

## قابلیت‌های داشبورد (۱۰ تب)

| # | تب | چه چیزی نشان می‌دهد |
|---|---|---|
| ۱ | 🌡️ نقشه حرارتی شعله | سرعت شعله، دما و NOx پیش‌بینی‌شده توسط مدل جانشین (Gaussian Process) در کل فضای طراحی |
| ۲ | ⚖️ مرز بهینه Pareto | بهینه‌سازی چندهدفه (NSGA-II) بین سرعت شعله و NOx |
| ۳ | 📊 مقایسه رادار | مقایسه‌ی بصری H2 خالص، NH3 خالص، و ترکیب انتخابی |
| ۴ | ⏱️ زمان تأخیر اشتعال | نمودار Arrhenius برای ترکیب‌های مختلف سوخت |
| ۵ | 🧯 نقشه پایداری | محدوده‌ی اشتعال‌پذیری (lean/rich limits) با تشخیص خودکار خاموشی نزدیک محدوده |
| ۶ | 🔥 تصویر واقعی شعله | شبیه‌سازی زنده‌ی Cantera + تجسم بصری شعله بر پایه‌ی دمای واقعی محاسبه‌شده |
| ۷ | ✈️ شبکه راکتور RQL | مدل کاهش‌مرتبه‌ی محفظه‌ی احتراق توربین گاز (Rich-Quench-Lean) در فشار/دمای واقعی خروجی کمپرسور |
| ۸ | 🌬️ شعله نفوذی مخالف‌جریان | پیکربندی غیرپیش‌آمیخته (Counterflow Diffusion Flame) با تشخیص خاموشی |
| ۹ | 🌪️ حساسیت واکنش‌های NOx | تحلیل حساسیت تفاضل محدود روی ۴۵ واکنش مرتبط با NO |
| ۱۰ | 🌍 روایت کربن‌زدایی | مقایسه‌ی شدت کربن مسیرهای تولید سوخت (خاکستری/آبی/سبز) در برابر احتراق مستقیم |

## یافته‌های جالب

- **دقت بالا با داده‌ی کم:** با تعویض Random Forest به Gaussian Process +
  Latin Hypercube Sampling، با فقط ۱۵ نمونه به R²=0.977 برای سرعت شعله
  رسیدیم (در مقابل R²=0.79 با ۹۹ نمونه‌ی گرید یکنواخت قدیمی).
- **ری‌برن نیتروژن:** در شبکه‌ی راکتور RQL، افزایش زمان اقامت ناحیه‌ی
  خاموشی همیشه NOx را کم نمی‌کند — رادیکال‌های NHi باقی‌مانده از ناحیه‌ی
  غنی می‌توانند NO را احیا کنند، برخلاف قاعده‌ی کلاسیک RQL سوخت‌های
  هیدروکربنی.
- **آمونیای خالص در شعله‌ی نفوذی خاموش می‌شود:** بدون افزودن هیدروژن،
  شعله‌ی نفوذی NH3 خالص در نرخ‌های جرمی متعارف اصلاً مشتعل نمی‌ماند —
  یکی از دلایل اصلی ترکیب H2/NH3 در عمل.
- **کربن‌زدایی واقعی پیچیده‌تر از شعار است:** تولید هیدروژن خاکستری
  می‌تواند از خودِ احتراق مستقیم گاز طبیعی هم بیشتر CO2 معادل تولید کند.

## معماری فنی

```
داده‌ی شبیه‌سازی (Cantera) → مدل جانشین (Gaussian Process) → بهینه‌سازی (NSGA-II) → داشبورد (Streamlit)
```

- **موتور شیمیایی:** [Cantera](https://cantera.org) با مکانیزم Alzueta 2023
  (۴۲ گونه، ۲۸۱ واکنش) برای H2/NH3/CO
- **یادگیری ماشین:** scikit-learn (Gaussian Process Regression با کرنل Matérn)
- **بهینه‌سازی:** pymoo (NSGA-II)
- **رابط کاربری:** Streamlit + Plotly

## ساختار پروژه

```
h2nh3_project/
├── src/
│   ├── simulate.py              # هسته‌ی شبیه‌سازی شعله‌ی پیش‌آمیخته
│   ├── generate_dataset.py      # تولید دیتاست با Latin Hypercube Sampling
│   ├── train_surrogate.py       # آموزش مدل جانشین Gaussian Process
│   ├── optimize.py              # بهینه‌سازی چندهدفه NSGA-II
│   ├── ignition_delay.py        # محاسبه‌ی زمان تأخیر اشتعال
│   ├── stability_map.py         # نقشه‌ی محدوده‌ی اشتعال‌پذیری
│   ├── reactor_network.py       # شبکه‌ی راکتور RQL (توربین گاز)
│   ├── generate_rql_map.py      # اسکن پارامتری کامل RQL
│   ├── diffusion_flame.py       # شعله‌ی نفوذی مخالف‌جریان
│   ├── sensitivity_analysis.py  # تحلیل حساسیت واکنش‌های NOx
│   └── dashboard.py             # داشبورد تعاملی Streamlit (نقطه‌ی ورود اصلی)
├── data/                        # دیتاست‌های تولیدشده (CSV) و مدل‌های ذخیره‌شده
├── requirements.txt
└── README.md
```

## نصب و اجرای محلی

```bash
git clone https://github.com/Behnam9726/h2-nh3-combustion-explorer.git
cd h2-nh3-combustion-explorer
pip install -r requirements.txt
```

### تولید کامل خط‌لوله‌ی داده (اختیاری — دیتاست‌های آماده در `data/` موجودند)

اگر می‌خواهید همه‌ی داده‌ها را از صفر بسازید، به همین ترتیب اجرا کنید:

```bash
python src/generate_dataset.py       # ~۱۵-۳۰ دقیقه
python src/train_surrogate.py        # چند ثانیه
python src/optimize.py               # چند ثانیه
python src/ignition_delay.py         # ~۱-۲ دقیقه
python src/stability_map.py          # ~۱۰-۲۰ دقیقه
python src/sensitivity_analysis.py   # ~۵ دقیقه
python src/generate_rql_map.py       # ~۱-۲ دقیقه
```

### اجرای داشبورد

```bash
streamlit run src/dashboard.py
```
